# 06 · Demo 腳本與備援

比賽規定不能用簡報，所以直接操作實機，說明內容放在關於頁。初選有 2 分鐘展示和 1 分鐘問答，會評兩次；決選有 5 分鐘發表和 5 分鐘問答。

Demo 用 Android 實體手機，透過 Android Studio Running Devices 鏡像到筆電，再接 HDMI。

## 初選：2 分鐘

| 時間 | 說什麼 | 畫面 |
|---|---|---|
| 0:00–0:20 | 地圖對長者、孩子、外籍人士都太難。我們把地圖換成一支箭頭，帶他們走到正確方向的站牌 | 城市通首頁 → 服務 |
| 0:20–0:40 | 第一次打開先選誰在用和語言。同名站牌依方向分開列，選好要搭的車就好 | P1、P2、P4 |
| 0:40–1:15 | **轉動手機，箭頭跟著轉。** 不用看地圖，看一眼就懂；模擬走到轉彎，聽語音和感覺震動 | P6 |
| 1:15–1:30 | 切換成外籍人士和其他語言，同一個畫面就能用 | P9、P6 |
| 1:30–1:45 | 階段 2 完成時：長者在晚上，系統推薦少階梯、路燈較多的路，並說明原因 | P5（模擬晚上） |
| 1:45–2:00 | 全部開源，資料是 TDX、OSM、臺北市路燈；路線取得後不需要網路 | P8 |

畫面開始前先用 `?reset=1` 重來。

## 決選：5 分鐘

| 時間 | 內容 |
|---|---|
| 0:00–0:40 | 情境：長者看不懂地圖、孩子第一次自己走、外籍人士看不懂站名 |
| 0:40–3:30 | 完整走一次；用三種對象各走一小段；展示候選路線差別、走偏重算、切換語言 |
| 3:30–4:20 | 落地：資料來源與更新頻率、Docker、免費方案、App 改了哪些檔案、資訊局要做什麼 |
| 4:20–5:00 | 開源技術、公共利益、之後的方向（到站時間、家人 QR、施工繞路） |

## 評分對應

| 評分項目 | 我們靠什麼拿分 |
|---|---|
| 服務應用 | 直接對應「看不懂」的 4 個方向；3 種對象；路線依使用者調整 |
| 視覺呈現 | 導航畫面極簡；其他畫面跟隨 UI Kit；全部狀態都有畫面 |
| 技術完整度與穩定度 | 連續跑 3 次不出錯；斷網仍可導航；單元測試 |
| 服務完整度（決選） | Docker、快照腳本、維運說明、誠實標示限制 |
| 創意與公益（決選） | 不需要看懂地圖，也不需要看懂中文 |

## 現場備援

| 狀況 | 做法 |
|---|---|
| 室內 GPS 不準 | 用 `?demo=1` 模擬位置，朝向仍是真實羅盤，並明確說明是模擬行走 |
| 羅盤受場館鋼構干擾 | 開場前校正，移到遠離金屬的位置；模擬行走備有滑桿，並說明是備案 |
| 會場網路不穩 | 用手機熱點；Demo 路線已內建，不需要連線 |
| 評審要求關網路 | **先打開服務再關網路**；頁面快取在 WebView 內若驗證可行，才能說關著網路也打得開 |
| Cloud Run 冷啟動 | 10:00 前和決選前都打一次 `/api/health?deep=1` |
| 語音沒有聲音 | 開場前確認音量和語音包；畫面和震動仍可示範 |
| 白天要展示晚上 | 打開「模擬晚上」，畫面會標示 |

## 問答預備

| 問題 | 回答重點 |
|---|---|
| 為什麼不用 Google Maps？ | 比賽規定不能用。我們解決的也是另一個問題：不需要看懂地圖，而且會指向正確方向的站位 |
| 推薦路線的依據是什麼？ | 階梯、路口、路燈等資料，畫面會說出具體數字。沒有資料時不會宣稱安全或無障礙 |
| OSM 不完整怎麼辦？ | 沒標示的路口算「不確定」；沒有改善時直接說沒有更合適的路；資訊局未來可接入市府的路口和人行道圖資 |
| 定位不準怎麼辦？ | 會平滑處理，偏離要連續多次才重算；訊號弱時畫面會明說 |
| 羅盤不準怎麼辦？ | 實測誤差要在 15° 內。抓不到方向時，會請使用者校正，距離和語音繼續 |
| 翻譯可靠嗎？ | 預先翻譯並標示確認狀態。沒有母語者確認的語言，關於頁會寫明 |
| 手機沒有語音包呢？ | 改用文字和震動，主流程不受影響 |
| 個資怎麼處理？ | 不用登入，不讀 `userinfo`。位置只用於即時計算，放在 POST body，不寫入資料庫，也不進 log |
| 資料斷了怎麼辦？ | 站位、路口、路燈都是快照；路線取得後不需要網路 |
| 誰維運？ | 資料由交通部和市府更新；資訊局定期跑腳本更新路網與站位，服務本身沒有資料庫 |
| 怎麼整併？ | 網頁和後端可獨立部署；App 只新增服務設定和少量 Handler，都用 Flutter 跨平台套件 |
| iOS 呢？ | 架構上同一份網頁可以跑，但我們手邊沒有 Mac，**iOS 還沒驗證**。要補的是羅盤權限和語音測試 |
| AI 在哪裡？ | 開發時用 AI 寫程式並揭露。執行時沒有使用雲端 AI。翻譯是預先做好的（依隊友最終決定更新） |

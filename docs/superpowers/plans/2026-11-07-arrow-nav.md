# 跟著箭頭走 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在城市通內提供微服務，讓長者、兒童、外籍人士選好公車後，跟著一支箭頭走到正確站牌。

**Architecture:** 薄 App 加網頁。導航引擎是網頁端純函式，取得路線後可離線。FastAPI 讀快照並呼叫 Valhalla，沒有資料庫。

**Tech Stack:** Vue 3.5、Vite 8、TypeScript、Tailwind 4、Pinia、Vitest；FastAPI、pytest；Valhalla；Flutter 3.47.6（只有隊長）；Firebase Hosting、Cloud Run。

**Spec:** `docs/arrow-nav/`（README、01–07、`architecture/`）。計畫和規格衝突時，以規格為準，並回報給隊長。

## 怎麼用這份計畫

每個角色只做自己的區段。任務 ID 前綴就是角色，括號內是 [05 Stories](../../arrow-nav/05-stories.md) 的 ID。

**沒有排入：** Story I2（`routing` 改成 IAM 保護），階段 2 全部完成才考慮。

## Global Constraints

- 比賽規則：AGPL-3.0；不用 Google Maps、Mapbox；執行時不呼叫雲端 LLM 或翻譯服務；只用 MIT、BSD、Apache 等開源免費套件。
- 每個新套件和資料集，都要在同一個 commit 寫進根目錄 `README.md` 的清單。
- 使用者座標只放 POST body，不進網址和 log。TDX 金鑰不進 repo，也不進執行環境。
- 畫面和語音不能出現「安全」「無障礙」（英文 safe、accessible）。原因只來自量測數字。
- 句子全部在 `web/src/i18n/`，API 只回代碼和數字。
- 座標 WGS84；物件用 `lat`、`lon`；陣列用 `[lat, lon]`；距離 `M`；時間 `S`。
- 外部格式只出現在 `api/app/adapters/` 和 `scripts/`。
- 合約 15:30 凍結；要改時，受影響的人都要同意，並更新 [03](../../arrow-nav/03-contracts.md)。
- 路徑全英文：`C:\dev\2026CodeFest`。短分支 `<角色>/<任務>`，測試通過就併 `main`，每次併之前先 `git pull --rebase origin main`。
- 只能改自己區段列出的檔案；要動別人的檔案，先講。
- 組員要能解釋 AI 寫的程式碼（決選有問答）。

## Review Focus

1. **驗證錯誤回傳座標：** FastAPI 預設的 422 會回傳輸入內容。API 要改成只回代碼。測試在 API1。
2. **過時的重算回應：** 使用者已抵達或按結束後，重算結果才回來，不能把狀態拉回導航。測試在 NAV5。
3. **起點已在站牌旁：** 路線長度接近 0、幾何只有 1 點時，要直接抵達且只抵達一次，不能崩潰。測試在 NAV4、NAV5。
4. **羅盤權限被拒或沒有事件：** 距離、語音、抵達判斷要繼續。測試在 NAV5、NAV6。
5. **資料欄位是 `null`：** `en`、`bearing`、`headsign` 可能是 `null`，畫面不能出現 "null"，也不能崩潰。測試在 UI2、API3。
